# DDPM：先加噪，再学会一步步去噪

## 1. 出处、提出者与意义

Jonathan Ho、Ajay Jain、Pieter Abbeel 于 2020 年提出 [《Denoising Diffusion Probabilistic Models》](https://arxiv.org/abs/2006.11239)。它把图像生成拆成很多个较简单的去噪步骤：训练时故意给真实图像加噪，让网络猜加入的噪声；采样时从纯噪声反向走，逐步得到图像。这样的训练目标相对直接，成为后来许多图像生成方法的重要基础。本目录实现前向加噪、噪声预测训练、反向采样和一个小型时间条件 U-Net；这里的随机示例只检查计算路径，不能产生有意义的图片。

## 2. 源码导航与直观解释

源码：[ddpm.py](ddpm.py)。先看 `DDPM.__init__` 中的 `betas`、`alphas`、`alpha_bars`：它们规定每一步加多少噪声。接着看 `q_sample` 如何一次得到任意时间步的带噪图片，`training_loss` 如何训练 `TinyUNet` 预测噪声；最后看 `p_sample` 和 `sample` 如何倒序去噪。输入图像及网络输出均为 `[B,C,H,W]`，时间步 `t` 为 `[B]`；`TinyUNet` 用跳跃连接保留细节。可把它想成一张图被反复蒙上薄雾，网络学习识别并移除每一步的雾。从仓库根目录运行 `python DDPM/ddpm.py`。

## 3. 数学解释

设 `β_t` 是第 `t` 步噪声比例，`α_t=1−β_t`，`ᾱ_t=∏_{s=1}^t α_s`。若原图为 `x₀`，标准高斯噪声为 `ε`，则 `x_t=√ᾱ_t x₀+√(1−ᾱ_t)ε`，源码 `q_sample` 直接用此式，省去逐步加噪的循环。`training_loss` 最小化 `E‖ε−ε_θ(x_t,t)‖²`：网络看到带噪图和时间，回答噪声是什么。采样时 `p_sample` 先用预测噪声估计原图 `x̂₀=(x_t−√(1−ᾱ_t) ε_θ)/√ᾱ_t`，再按高斯后验得到 `x_{t−1}`；当 `t=0` 时不再加入随机噪声。`register_buffer` 保存噪声表，使其随模型移动设备但不会被训练更新。这里的小 U-Net 和采样步数是教学规模。
