# TextCNN：多种宽度的词组特征

## 1. 出处、提出者与意义

Yoon Kim 在 2014 年 [Convolutional Neural Networks for Sentence Classification](https://arxiv.org/abs/1408.5882) 中展示了简单卷积结构在句子分类上的效果：用不同宽度的卷积核观察二元、三元等局部词组，再对整句做最大池化。这个模型让人看到 CNN 不只处理图像，也可把序列中的局部模式汇总成固定长度表示。

## 2. 源码导航与直观解释

[textcnn.py](textcnn.py) 中 `embedding` 把 `[B,T]` 词 ID 变为 `[B,T,E]`；不同 `kernel_size` 的 `Conv1d` 沿时间滑动。每个卷积的结果取时间维最大值，拼接后经 dropout 和线性层输出 `[B,类别数]`。运行 `python TextCNN/textcnn.py`。例子使用随机可训练词向量，而原论文比较了静态、可微调和多通道预训练词向量。

## 3. 数学解释

宽度为 `k` 的滤波器在位置 `t` 读取连续 `k` 个词向量并计算 `c_t=ReLU(W·[e_t;…;e_{t+k−1}]+b)`。最大池化取 `ĉ=max_t c_t`，表示“这个模式在句中是否强烈出现”，同时不要求它出现在固定位置。不同 `k` 的滤波器分别覆盖不同长度的词组；所有 `ĉ` 拼接后做分类。源码的 `Conv1d`、`amax(dim=-1)` 与此一一对应。

假设句子有 7 个词、卷积核宽度为 3、没有填充，那么该滤波器会产生 5 个位置的响应；最大池化只保留其中最大的一个。多个滤波器会得到多个标量，多个宽度会覆盖不同长度的词组。该结构适合整句分类，但全局最大池化会丢失命中位置，不能直接拿来做逐词标注。

运行示例可尝试把句子长度从 7 改成 3；最宽的 4 词卷积核不再有合法窗口，源码会给出清楚的输入长度错误。
