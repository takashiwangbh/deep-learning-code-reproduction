# LSTM：用门控制长期记忆

## 1. 出处、提出者与意义

Sepp Hochreiter 和 Jürgen Schmidhuber 在 1997 年 [Long Short-Term Memory](https://doi.org/10.1162/neco.1997.9.8.1735) 中提出 LSTM，以改善普通 RNN 长程依赖难学的问题。它把隐藏状态 `h` 和细胞状态 `c` 分开，让网络通过门决定写入、保留和读出什么。这里实现标准 LSTM 门控单元，而非某个应用场景的完整训练系统。

## 2. 源码导航与直观解释

[lstm.py](lstm.py) 的 `LSTMCell.forward` 把两次线性变换的结果切成输入门 `i`、遗忘门 `f`、候选记忆 `g`、输出门 `o`；`LSTM.forward` 逐时间步调用它。输入 `[B,T,D]`，输出所有隐藏状态 `[B,T,H]`，并返回最终 `(h,c)`。运行 `python LSTM/lstm.py`。源码没有调用 `nn.LSTM`，四种门和记忆更新都可直接定位。这里采用后来广泛使用、包含遗忘门的标准现代写法；1997 年最初版本的具体门控配置与其并不完全相同。

## 3. 数学解释

令 `[iₜ,fₜ,gₜ,oₜ]` 来自 `Wₓxₜ+Wₕhₜ₋₁+b` 的四段；三个门经 sigmoid 限在 0 到 1，候选 `gₜ` 经 tanh。更新为 `cₜ=fₜ⊙cₜ₋₁+iₜ⊙gₜ`，再算 `hₜ=oₜ⊙tanh(cₜ)`。遗忘门接近 1 时旧记忆可直接沿加法路径保留，接近 0 时则被擦除。`⊙` 是逐元素乘法，形状均为 `[B,H]`。这个显式加法路径是 LSTM 相比普通 RNN 的关键。

可以把所有线性层权重清零，并让初始细胞状态为 1：此时各 sigmoid 门均为 0.5，候选记忆为 0，所以更新后的细胞状态正好是 0.5。检查脚本用这个数值例子验证门控公式。读代码时还应注意 h 和 c 的形状相同，但职责不同：c 承载累积记忆，h 供当前层输出和下一步门控使用。
