# Autoencoder：把数据压缩后再还原

## 1. 出处、提出者与意义

自编码器早于深度学习热潮就已存在。本项目选择 Geoffrey Hinton 与 Ruslan Salakhutdinov 2006 年发表于 *Science* 的 [《Reducing the Dimensionality of Data with Neural Networks》](https://doi.org/10.1126/science.1127647) 作为代表论文；两位作者并非“自编码器的唯一发明者”。论文研究的是：一张图片或一组特征可能有很多数字，能否把它压进很短的向量，再尽量还原？如果能，短向量就抓住了数据的主要结构。它让深层网络学习非线性低维表示成为一条重要路线。本目录演示编码器、瓶颈和解码器；原论文的逐层预训练没有包含在教学源码中。

## 2. 源码导航与直观解释

源码：[autoencoder.py](autoencoder.py)。`Autoencoder.encoder` 把输入变成短向量 `z`，`decoder` 根据 `z` 重建；`forward` 同时返回重建结果与 `z`，方便比较和可视化。`reconstruction_loss` 计算重建误差。输入图像 `[B,C,H,W]` 会先展平为 `[B,D]`；默认 `D=784`、瓶颈维度为 `32`，输出重建为 `[B,784]`。直观地看，编码器像“摘要员”，解码器像只看摘要的“复述者”；摘要越短，就越必须保留有用信息。从仓库根目录运行 `python Autoencoder/autoencoder.py`，脚本用随机图像完成前向和反向传播，无需数据下载。

## 3. 数学解释

设输入为向量 `x∈R^D`，编码器为 `f_θ`、解码器为 `g_φ`，则 `z=f_θ(x)`，`x̂=g_φ(z)`。源码的 `encoder` 和 `decoder` 正好对应这两步；`latent_dim<D` 形成信息瓶颈。训练目标为 `L=(1/N)Σᵢ‖x̂ᵢ−xᵢ‖²`，即 `reconstruction_loss` 使用的均方误差：每个重建值离原值越远，惩罚越大。反向传播同时调整 `θ` 和 `φ`，让网络学会“怎样压缩才仍能还原”。例如 784 个像素压成 32 个数，不要求 32 个数逐一对应具体像素，它们是共同编码出的特征；也不能仅凭随机输入上的低损失推断其表示已经有用。
