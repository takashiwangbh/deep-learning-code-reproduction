# VGG-16：反复堆叠 3×3 卷积

## 1. 出处、提出者与意义

Karen Simonyan 和 Andrew Zisserman 在 2014 年提出 [《Very Deep Convolutional Networks for Large-Scale Image Recognition》](https://arxiv.org/abs/1409.1556)。他们研究的核心问题是：在结构尽量规则的情况下，把卷积网络加深是否有效？VGG-16 以一串小的 3×3 卷积逐级增加通道，在当时的大规模图像识别上显示了深度的重要性。规则的“卷积若干次、池化一次”结构也使它成为理解 CNN 的常见基准。

## 2. 源码导航与直观解释

在 [vgg16.py](vgg16.py) 中读 `channels` 列表：数字代表本层输出通道，`"M"` 代表一次 2×2 最大池化。循环将列表展开成 `features`；它包含 13 个卷积权重层。`classifier` 再接三个全连接权重层，所以称为 16。`forward` 的路线是图像 `[B,3,H,W]` → 特征图 → 全局定尺寸池化 → 展平 → `[B,类别数]` logits。试着把 `channels` 中某一个 `"M"` 删除，可以看到后续空间尺寸和计算量如何变化。

从仓库根目录运行 `python "VGG/vgg16.py"`。默认参数接近论文大模型；脚本底部使用较窄通道和较小分类头供 CPU 运行，不包含预训练权重。

## 3. 数学解释

连续两个带 `padding=1` 的 3×3 卷积会让一个输出位置间接看到约 5×5 的输入区域，三个则约 7×7；但它们之间各有一次 ReLU，表达能力比一次大卷积更灵活。若输入、输出通道都为 `C`，一个 5×5 卷积约需 `25C²` 个权重，两次 3×3 约需 `18C²`；这个对比解释了小卷积核为何有吸引力。源码里 `Conv2d(..., kernel_size=3, padding=1)` 保持空间尺寸，`MaxPool2d(2,2)` 才把宽高减半。五次池化把 224 大小缩到约 7，最后由分类头输出每类分数。
