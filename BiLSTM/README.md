# BiLSTM：同时读取左右文

## 1. 出处、提出者与意义

Mike Schuster 和 Kuldip K. Paliwal 在 1997 年 [Bidirectional Recurrent Neural Networks](https://doi.org/10.1109/78.650093) 中提出双向循环建模；与 Hochreiter、Schmidhuber 的 LSTM 单元结合，形成常见的 BiLSTM。单向序列模型只知道当前词左侧的信息，双向模型还让当前位置利用右侧上下文，因此常用于标注、分类等非自回归任务。

## 2. 源码导航与直观解释

[bilstm.py](bilstm.py) 本地实现 `LSTMCell` 的四门更新，`BiLSTM._scan` 分别从左到右、从右到左运行两套独立参数，最后按通道拼接同一位置的两种状态。输入 `[B,T,D]`，输出 `[B,T,2H]`；运行 `python BiLSTM/bilstm.py`。代码显式展开时间循环，便于观察方向变化；实际变长批次通常还需按长度屏蔽 padding。

## 3. 数学解释

正向状态满足 `→h_t=LSTM(x_t,→h_{t−1})`，反向状态满足 `←h_t=LSTM(x_t,←h_{t+1})`，最终表示 `h_t=[→h_t;←h_t]`。两方向的参数互不共享，每侧宽度 `H`，所以拼接为 `2H`。单个 LSTM 单元内有 `c_t=f_t⊙c_{t−1}+i_t⊙g_t` 与 `h_t=o_t⊙tanh(c_t)`；源码的 `_scan(reverse=True)` 实际反转遍历顺序，再把结果还原到原时间索引。

改变序列最后一个输入，正向网络在第一个位置的状态不应变化，而反向网络在第一个位置可能变化，因为反向扫描已经看过结尾。检查脚本利用这个性质验证方向没有写反。双向信息要求事先拿到完整序列，所以不能直接用作严格从左到右的下一词生成器。

每个方向各有一套输入矩阵和隐藏矩阵，参数量也因此多于单向 LSTM；输出通道增加是拼接结果，不是把两个方向求平均。
