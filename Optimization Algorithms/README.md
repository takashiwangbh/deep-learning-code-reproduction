# Optimization Algorithms（优化算法）

## 1. 出处、提出者与意义

训练网络的最后一步是根据梯度修改参数。最基本的随机梯度下降（SGD）沿着损失下降方向走一步；动量法让前几步的方向也影响当前更新，减轻来回摆动。Diederik P. Kingma 与 Jimmy Ba 在 [Adam: A Method for Stochastic Optimization](https://arxiv.org/abs/1412.6980)（2014）中提出 Adam：同时记录梯度的一阶、二阶移动平均，为不同参数调整有效步长。这里把三种更新都展开写出来，方便理解 `optimizer.step()` 实际做了什么。

优化器只接收参数和梯度，不知道模型是图像网络还是语言模型。因此先弄懂本项目，再看后续训练代码，能分清“网络如何计算预测”与“参数如何被更新”。

## 2. 源码导航与直观解释

[optimizers_numpy.py](optimizers_numpy.py) 中的 `SGD.step` 逐个读取参数名和同名梯度；`momentum=0` 是普通 SGD，设为正数就保存上一步速度。`Adam.step` 为每个参数保存 `first_moment` 与 `second_moment`，并记录步数以做偏差校正。代码只依赖 NumPy，传入的参数字典会被原地修改。

从仓库根目录运行 `python 'Optimization Algorithms/optimizers_numpy.py'`。小例子最小化 `(x−2)²`，因此可以检查最终 `x` 是否接近 2。若要接入其它模型，把 `parameters` 中的数组与 `gradients` 中同名数组交给 `step` 即可；梯度如何得到，可回看多层感知机项目。

## 3. 数学解释

令 `θ` 表示某个参数，`gₜ = ∂L/∂θ` 是第 `t` 步的梯度，`η` 是学习率。普通 SGD 是 `θₜ = θₜ₋₁ − ηgₜ`：若梯度为正，参数减小；梯度为负，参数增大。动量法在源码中写为 `vₜ = μvₜ₋₁ + gₜ`、`θₜ = θₜ₋₁ − ηvₜ`，其中 `μ` 控制保留过去方向的程度。

Adam 先计算 `mₜ = β₁mₜ₋₁ + (1−β₁)gₜ` 与 `vₜ = β₂vₜ₋₁ + (1−β₂)gₜ²`。`m` 近似平均方向，`v` 近似梯度平方的平均大小。因为二者初始为 0，前几步会偏小，所以用 `m̂ₜ=mₜ/(1−β₁ᵗ)`、`v̂ₜ=vₜ/(1−β₂ᵗ)` 校正。最终 `θₜ=θₜ₋₁−ηm̂ₜ/(√v̂ₜ+ε)`；小常数 `ε` 防止分母为零。源码中每个式子都对应同名变量，可用单个参数先手算一步再运行。
