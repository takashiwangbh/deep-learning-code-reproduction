# GCN：在图的邻居之间传递信息

## 1. 出处、提出者与意义

Thomas N. Kipf 与 Max Welling 于 2016 年提出、2017 年发表于 ICLR 的 [《Semi-Supervised Classification with Graph Convolutional Networks》](https://arxiv.org/abs/1609.02907)。普通卷积依赖图片整齐的像素网格，而引用网络、社交网络等数据只有“节点与边”。GCN 提出简单有效的图卷积层，让每个节点聚合邻居的特征；即使只知道少数节点的标签，也能借助连接关系学习分类。本目录展示邻接矩阵归一化、两层图卷积与只在有标签节点上计算损失的最小例子。

## 2. 源码导航与直观解释

源码：[gcn.py](gcn.py)。`normalize_adjacency` 给每个节点加一条指向自己的边，再按节点度数缩放邻接矩阵；`GraphConv.forward` 先做线性变换，再用归一化矩阵聚合邻居；`GCN.forward` 连续做两次传播并输出每个节点的类别 **logits** `[N,C]`。输入 `features` 是 `[N,F]`，`adjacency` 是 `[N,N]`，其中非零位置表示连接。直观地看，每个节点先听自己和邻居说话，更新一次理解，再听更新后的邻居说话；两层后能用到两跳范围的信息。根目录运行 `python GCN/gcn.py`。

## 3. 数学解释

设 `A` 为邻接矩阵、`I` 为自环，`Ã=A+I`；节点度数构成对角矩阵 `D̃`。源码 `normalize_adjacency` 计算 `Â=D̃^{-1/2} Ã D̃^{-1/2}`。加自环使节点保留自己的信息，左右度数归一化避免高连接度节点单纯因邻居多而数值过大。单层公式是 `H^{(l+1)}=σ(Â H^{(l)} W^{(l)})`：`H` 是每个节点的一行特征，`W` 是可学习线性变换，`Â` 把邻居特征加权汇总，`σ` 是激活函数。`GraphConv` 实现 `ÂHW`，`GCN` 在第一层后加 ReLU 和 dropout，第二层给分类分数。若只有部分节点有标签，交叉熵只对这些节点计算，未标注节点仍能通过图结构参与特征传播。
