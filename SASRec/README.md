# SASRec：根据行为序列预测下一件商品

## 1. 出处、提出者与意义

Wang-Cheng Kang 和 Julian McAuley 在 2018 年提出 [《Self-Attentive Sequential Recommendation》](https://arxiv.org/abs/1808.09781)。用户最近看的商品不一定最能解释下一次点击：若用户长期关注摄影器材，一个更早的相机点击仍可能比刚浏览的杂项商品重要。SASRec 用因果自注意力让每一步从**已经发生的行为**中挑有用的信息，同时允许整个训练序列并行计算。它是序列推荐的常用基线。

## 2. 源码导航与直观解释

[sasrec.py](sasrec.py) 中 `SASRec` 将历史商品 ID `[B,T]` 转为商品嵌入并加入位置嵌入；`SASBlock` 做自注意力、残差、归一化和逐位置前馈变换。`causal` 上三角掩码阻止当前时刻看到未来商品，`padding` 掩码排除末尾补齐的 0。输出 `[B,T,V+1]` 是每个位置对应的下一商品分数；训练时用第 `t` 个位置的分数预测第 `t+1` 个真实商品，PAD 位置应从损失中排除。运行 `python SASRec/sasrec.py`。示例要求右侧补齐、首位有效，不包含负采样、完整推荐评估或大数据训练。

## 3. 数学解释

位置 `t` 的表示 `x_t=e(item_t)+p_t`，其中 `e` 是商品嵌入，`p` 是位置嵌入。注意力分数 `QKᵀ/√d` 经 softmax 后加权读取 `V`，但第 `t` 行只允许读取列 `≤t`；源码的 `triu(1)` 布尔矩阵将未来列遮住。随后残差与前馈网络得到 `h_t`。候选商品 `j` 的分数采用共享嵌入点积 `s_{t,j}=h_t·e(j)`，对应源码末尾的矩阵乘法；概率由 softmax 给出。若把序列后半段改掉，前半段的分数应该完全不变，这正是“因果”在推荐训练中的可检验含义。
