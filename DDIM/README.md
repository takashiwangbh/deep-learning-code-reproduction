# DDIM：用更少的去噪步数采样

## 1. 出处、提出者与意义

Jiaming Song、Chenlin Meng 与 Stefano Ermon 在 2020 年提出、ICLR 2021 发表 [《Denoising Diffusion Implicit Models》](https://arxiv.org/abs/2010.02502)。DDPM 通常一步步沿完整时间表反向去噪；DDIM 保留相同的噪声预测训练目标，却可以跨越多个时间点采样。在 `η=0` 时，给定初始噪声和固定模型，路径是确定性的；改变 `η` 则能引入随机性。这是理解扩散采样器与训练目标可分开设计的重要例子。

## 2. 源码导航与直观解释

打开 [ddim.py](ddim.py)：`DDIM.__init__` 保存完整训练时间表，`q_sample` 与 `training_loss` 使用和 DDPM 一样的加噪、噪声预测损失；`step` 给定当前图 `x_t`、预测噪声和下一个更早时间点，直接跳过去；`sample` 从全部训练时间中选少数 `inference_steps`。`TinyDenoiser` 只是本地可读的时间条件小卷积网络，输入输出均 `[B,1,8,8]`，时间为 `[B]`。根目录运行 `python DDIM/ddim.py` 会检查相同初始噪声的确定性。未训练的模型只能演示算法计算，不能生成有意义的图。

## 3. 数学解释

记 `ᾱ_t=∏_{s≤t}(1−β_s)`，由噪声预测 `ε_θ(x_t,t)` 先估计干净图 `x̂₀=(x_t−√(1−ᾱ_t)ε_θ)/√ᾱ_t`。设要跳到更早的 `s<t`，DDIM 更新为 `x_s=√ᾱ_s x̂₀+√(1−ᾱ_s−σ²)ε_θ+σ ε`，其中 `σ=η√[(1−ᾱ_s)/(1−ᾱ_t)]√[1−ᾱ_t/ᾱ_s]`。代码把 `η` 限在 `[0,1]`，避免方向项根号内变负；`step` 的 `estimated_clean`、`direction` 和最后的可选噪声正对应三项。`s=-1` 表示最终输出，此时 `ᾱ_s=1`，不会再加噪。当 `η=0` 时 `σ=0`，没有额外随机抽样，因此相同初始噪声必然得到同一结果。`sample` 中的时间点可以跳过许多训练步，而不需要重新训练噪声网络。
