# Perceptron：最早的可学习线性分类器

## 1. 出处、提出者与意义

Frank Rosenblatt 在 1958 年的论文 [The Perceptron: A Probabilistic Model for Information Storage and Organization in the Brain](https://doi.org/10.1037/h0042519) 中提出感知机。它回答最基础的问题：一组输入特征能否通过逐次纠错，学出一条把两类样本分开的直线或超平面？感知机没有隐藏层，却给后来的神经网络提供了“参数随错误样本更新”的原型。

## 2. 源码导航与直观解释

源码 [perceptron.py](perceptron.py) 的 `decision_function` 计算线性分数，`predict` 把分数变成 ±1，`fit` 每遇到误分类样本便改权重和偏置。输入 `x` 是 `[N,D]`，标签 `y` 是 `[N]` 且只能为 ±1。运行 `python Perceptron/perceptron.py` 可观察每轮错误数下降。先读 `fit` 内的单样本循环，最容易理解它如何学习。

## 3. 数学解释

令分数 `s=wᵀx+b`，预测为 `sign(s)`。若真实标签 `y∈{−1,+1}` 且 `y·s≤0`，此样本位于错误一侧或边界上，更新 `w←w+ηyx`、`b←b+ηy`。其中 `η` 是步长；正样本会把边界朝正确方向推，负样本则反向推。对线性可分数据，持续训练能找到某个分离超平面；若数据本身不能线性分开，错误数未必归零。这里保留了原始在线更新，没有把算法藏在优化器里。

例如把样本 (2,1) 标为正类，若当前分数为负，权重就沿 (2,1) 方向移动；下次同一正样本的分数增加了 η‖x‖²（偏置还会增加 η）。这个具体增量能帮助检查更新符号是否写反。模型只产生线性边界，因此面对 XOR 一类不可线性分开的数据，需要增加隐藏层或特征变换。
