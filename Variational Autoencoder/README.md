# VAE：让潜变量成为可采样的分布

## 1. 出处、提出者与意义

[《Auto-Encoding Variational Bayes》](https://arxiv.org/abs/1312.6114) 由 Diederik P. Kingma 与 Max Welling 于 2013 年提出。普通自编码器给每个输入一个确定的编码；VAE 给它一个**概率分布**，并约束这些分布靠近同一个先验。这样既能压缩、重建，也能先从标准正态分布随机取一个潜变量，再由解码器生成新样本。关键突破是重参数化技巧：把随机性移到独立噪声里，使编码器仍能通过反向传播学习。这里保留这个核心机制，采用小型全连接网络，供初学者读公式与源码。

## 2. 源码导航与直观解释

源码：[vae.py](vae.py)。`VAE.forward` 将输入 `[B,D]` 或图像 `[B,C,H,W]` 展平，编码为每个样本的均值 `mu` 和对数方差 `logvar`，再取样 `z`，输出重建 **logits** `[B,D]`。`reparameterize` 显式完成采样；`elbo_loss` 分别返回总损失、重建项、KL 项；`sample` 不给原图，直接从先验采样并生成。可以把 `mu` 想成潜空间中的“中心”，方差表示“允许在中心附近活动多远”。从仓库根目录运行 `python 'Variational Autoencoder/vae.py'`；示例使用 `[0,1]` 随机图像，不下载数据。

## 3. 数学解释

编码器给出 `q_φ(z|x)=N(μ(x), diag(σ²(x)))`。若直接对随机采样 `z` 求导很困难，源码改写成 `ε∼N(0,I)`、`z=μ+exp(½ logσ²)·ε`：随机数 `ε` 与参数无关，梯度便能从 `z` 流回 `μ` 与 `logvar`。总损失是负 ELBO：`L=−E[log p_θ(x|z)]+KL(q_φ(z|x)‖N(0,I))`。第一项要求重建像原图，`elbo_loss` 用适合 `[0,1]` 像素的 `binary_cross_entropy_with_logits`；第二项要求潜分布别散得过远，代码计算 `−½Σ(1+logσ²−μ²−σ²)`。若只优化重建，潜空间可能无法从标准正态顺利采样；若 KL 太强，重建可能失去细节。两项的平衡正是 VAE 的核心。
