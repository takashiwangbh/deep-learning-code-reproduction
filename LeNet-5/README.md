# LeNet-5：从像素到数字类别

## 1. 出处、提出者与意义

1998 年，Yann LeCun、Léon Bottou、Yoshua Bengio 和 Patrick Haffner 在 [《Gradient-Based Learning Applied to Document Recognition》](https://bottou.org/papers/lecun-98h)中系统展示了 LeNet-5。它面对的是手写数字和文档识别：同一个数字移到图片的不同位置，识别结果不应轻易改变。卷积让同一组小滤镜在整张图上反复使用，池化则逐步压缩位置；这比把每个像素直接连到所有神经元更适合图像，也成为后来卷积网络的基本样式。

## 2. 源码导航与直观解释

源码是 [lenet5.py](lenet5.py)，入口类为 `LeNet5`。输入是一批灰度图 `[B,1,32,32]`，输出是 `[B,类别数]` 的原始分类分数（logits）。先看 `self.features`：三次卷积负责找局部图案，两次平均池化让图案逐渐浓缩；再看 `self.classifier`：把最后的 120 个特征变成类别分数。`forward` 只是把两段串起来。把一张图想成从“笔画边缘”到“数字整体形状”的逐层加工，会更容易理解这些层的顺序。

从仓库根目录运行 `python "LeNet-5/lenet5.py"`；随机输入只检查形状，训练时把 logits 交给交叉熵损失。为让结构容易阅读，本实现把原论文 C3 的部分通道连接改为普通全通道卷积，把可学习的 S 层改为固定平均池化，因此它是结构教学版，不与原权重逐项兼容。

## 3. 数学解释

卷积层在位置 `(i,j)` 的一个输出可写成 `y[i,j]=b+Σ(u,v,c) W[u,v,c]·x[i+u,j+v,c]`：`W` 是一小块共享权重，`c` 是输入通道。`nn.Conv2d` 就执行这一步。同一个 `W` 扫过所有位置，所以网络能在不同位置寻找相似笔画。无填充的 5×5 卷积把宽高从 32 变为 `32−5+1=28`，2×2 池化再变为 14；源码注释沿着 `32→28→14→10→5→1` 标出了完整尺寸。池化是局部取平均，直观上是“附近有这个特征就保留一点证据”。最后 `Linear` 做加权求和并输出每一类的分数；最大分数对应预测类别。
