# Vanilla RNN：沿时间递推的隐藏状态

## 1. 出处、提出者与意义

Jeffrey L. Elman 在 1990 年 [Finding Structure in Time](https://doi.org/10.1207/s15516709cog1402_1) 中系统展示了简单循环网络如何通过上下文单元处理序列。与普通前馈网络不同，RNN 让本步的表示依赖上一步的隐藏状态，因此一句话或一段时间序列的信息能够向后传递。它也是理解 LSTM、GRU 和现代状态空间模型的起点。

## 2. 源码导航与直观解释

[vanilla_rnn.py](vanilla_rnn.py) 的 `VanillaRNN.forward` 显式循环时间维：每一步将当前输入经过 `input_map`，上一步隐藏状态经过 `hidden_map`，相加后取 `tanh`。输入 `[B,T,D]`，返回所有隐藏状态 `[B,T,H]` 与最终状态 `[B,H]`。运行 `python 'Vanilla RNN/vanilla_rnn.py'`；可单步跟踪 `h` 的变化。代码未调用 `nn.RNN`，因此递推公式直接可见。

## 3. 数学解释

第 `t` 步为 `hₜ=tanh(Wₓxₜ+Wₕhₜ₋₁+b)`。`hₜ` 既是当前输出，也是传给下一步的记忆。若把最终状态送给分类器，就能给整段序列分类；若保留每个状态，就能逐位置预测。训练时梯度会沿多步反传，反复乘以状态转移的导数，可能衰减或放大；这解释了简单 RNN 难以长期记忆，也解释了后来的门控结构为何重要。

可以把前四个输入完全保持不变，只改最后一个输入：按递推式，前四个隐藏状态必须不变，只有最后状态改变。反过来，改第一个输入可能影响所有后续状态。这个简单实验能区分真正有时间递推的模型与只对每个时间步独立做线性变换的模型。

作为练习，可把隐藏维度从 8 改成 16；输入和时间长度不变，最后一维会随之翻倍。隐藏维度决定记忆容量，也决定递推矩阵的大小。
