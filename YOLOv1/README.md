# YOLOv1：一次前向完成目标检测

## 1. 出处、提出者与意义

Joseph Redmon、Santosh Divvala、Ross Girshick 和 Ali Farhadi 在 2015 年提出 [《You Only Look Once: Unified, Real-Time Object Detection》](https://arxiv.org/abs/1506.02640)。目标检测既要判断类别，也要给出物体的位置。YOLOv1 把这两件事放到一次整图网络前向里，直接预测网格中的边界框、置信度与类别分数，建立了单阶段检测的重要路线。它特别强调把整个检测流程作为一个可端到端优化的问题。

## 2. 源码导航与直观解释

源码 [yolov1.py](yolov1.py) 包含三块：`YOLOv1` 的 24 层卷积主干和全连接预测头；`box_iou`/`responsible_box_mask` 根据预测框与真值框重合程度，选出负责学习物体位置的框；`YOLOv1Loss` 计算坐标、置信度和类别损失。输入是图像 `[N,3,H,W]`，输出 `[N,S,S,C+5B]`：`S×S` 个网格，每格有 `C` 个类别分数及 `B` 个 `(x,y,w,h,confidence)`。真值需额外提供物体掩码、框和 one-hot 类别。

从仓库根目录运行 `python "YOLOv1/yolov1.py"`，脚本使用缩窄的小模型演示前向与损失。源码没有标注文件转换、预测框筛选和非极大值抑制；宽高由 `softplus` 保证为正，原论文最后预测层则完全线性。

## 3. 数学解释

框的 `(x,y)` 是所在网格内的偏移，`(w,h)` 是整图比例。`box_iou` 把它们换到整图坐标，计算 `IoU=交集面积/并集面积`。每个有物体网格用 IoU 最大的候选框负责坐标：`responsible_box_mask` 实现这一选择。损失可看成五块：`5·[(x−x*)²+(y−y*)²]`、`5·[(√w−√w*)²+(√h−√h*)²]`、责任框置信度误差、`0.5·`非责任框置信度误差、物体格类别误差。星号表示真值。代码把 `√w/√h` 放在坐标项，是为了让小框的尺寸误差也得到足够重视；责任框的置信度目标是其 IoU，而空格及非责任框的目标是 0。`B` 个框只有一个负责坐标学习，这解释了为何必须先求 `responsible_box_mask`。
