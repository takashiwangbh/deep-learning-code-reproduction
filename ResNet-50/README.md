# ResNet-50：瓶颈残差块构成的经典视觉基线

## 1. 出处、提出者与意义

Kaiming He、Xiangyu Zhang、Shaoqing Ren、Jian Sun 在 2015 年提出 [《Deep Residual Learning for Image Recognition》](https://arxiv.org/abs/1512.03385)。仓库已有 ResNet-34，它使用每块两层 3×3 卷积；ResNet-50 则采用瓶颈块，以 `1×1 → 3×3 → 1×1` 三层卷积先缩窄、处理、再扩展通道，令更深网络的计算量可控。ResNet-50 也长期是分类、检测、分割论文常用的主干基线；单独列出它能帮助新手理解为何“残差学习”和具体深度配置是两个层次。

## 2. 源码导航与直观解释

[resnet50.py](resnet50.py) 里先看 `Bottleneck`：主路三层卷积，捷径 `shortcut` 在通道数或分辨率变化时用 `1×1` 投影；两路相加后再激活。`ResNet50` 由开头 `7×7` 卷积与池化、四组 `3,4,6,3` 个瓶颈块、全局平均池化和分类头组成。默认 `base_width=64` 对应经典通道配置，输出 `[B,1000]`；运行 `python ResNet-50/resnet50.py` 时使用缩窄的 `base_width=8` 和随机 `[2,3,64,64]` 图像，便于 CPU 上检查 `[2,7]` 的输出与反向传播。示例不提供 ImageNet 权重或论文性能指标。

## 3. 数学解释

残差块计算 `y=ReLU(F(x)+S(x))`。在瓶颈块中，`F` 依次用 `1×1` 把宽度降为 `C`、`3×3` 处理空间关系、`1×1` 扩为 `4C`；`S(x)` 在形状相同时是 `x`，否则是步长合适的投影 `W_s x`。投影保证主路与捷径能相加；源码的 `main` 和 `shortcut` 正对应这两项。四组共 `3+4+6+3=16` 个瓶颈块，每块三层可学习卷积共 48 层，再计开头卷积和末尾全连接层，得到名称中的 50 层。下采样在每组首块完成；本文件把步长放在第一层 `1×1` 卷积，遵循论文原始配置，而不少后续库改放在 `3×3` 层。
