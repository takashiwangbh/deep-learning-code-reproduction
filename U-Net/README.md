# U-Net：给图像中的每一个像素分类

## 1. 出处、提出者与意义

Olaf Ronneberger、Philipp Fischer 和 Thomas Brox 在 2015 年提出 [《U-Net: Convolutional Networks for Biomedical Image Segmentation》](https://arxiv.org/abs/1505.04597)。普通分类网络只回答“图里有什么”，医学图像分割还需要回答“目标的边界在哪些像素”。U-Net 左侧逐步缩小图像、理解整体语义；右侧逐步放大，同时通过横向跳接拿回早期的精细位置。其编码器—解码器形状像字母 U，成为像素级预测的经典结构。

## 2. 源码导航与直观解释

源码 [unet.py](unet.py) 的 `UNet.forward` 最适合顺着读：`e1` 到 `e4` 保存四层不同尺度的图像线索；`bottom` 处理最小、最抽象的特征图；`up4` 到 `up1` 把图像逐级放大，并在每一级接回对应的 `e`。`Up.forward` 中 `torch.cat([skip,x],dim=1)` 是关键跳接。输入 `[B,输入通道,H,W]`，输出 `[B,类别数,H,W]`，每个像素都有一组 logits。多类别训练可用像素标签 `[B,H,W]` 与交叉熵。

从仓库根目录运行 `python "U-Net/unet.py"`。示例使用奇数高宽，源码会补齐上采样的边界以正确拼接。它使用 `padding=1` 保持原图尺寸；原论文采用无填充卷积与裁剪跳接，这是明确的教学变体。

## 3. 数学解释

每次 2×2 最大池化大致把 `H×W` 变为 `(H/2)×(W/2)`，感受野随深度增大，网络能判断一块区域是什么；但仅靠低分辨率特征，上采样很难还原边界。设编码器特征为 `e_l`、上采样特征为 `u_l`，解码器计算 `d_l=Conv([e_l,u_l])`；方括号是通道拼接。代码中的 `Up` 正好先做转置卷积得到 `u_l`，再 `torch.cat` 和 `DoubleConv`。最后 1×1 卷积把每个位置的 `C` 维特征变成类别数个分数，不改变位置。这样既有“这是什么”的大范围线索，也有“它具体在哪”的浅层线索。
