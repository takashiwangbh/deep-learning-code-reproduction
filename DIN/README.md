# DIN：候选商品决定用户兴趣的重点

## 1. 出处、提出者与意义

Guorui Zhou、Chengru Song、Xiaoqiang Zhu 等人在 2017 年的 [《Deep Interest Network for Click-Through Rate Prediction》](https://arxiv.org/abs/1706.06978) 提出 DIN。传统推荐模型把用户历史点击压成一个固定向量，无论现在推荐什么商品，历史中的每个商品都按同一种方式参与预测。DIN 改为针对**当前候选商品**激活相关的历史行为：推荐相机时，相机配件的历史点击可能更重要；推荐图书时，阅读偏好可能更重要。这是一种面向目标的注意力聚合，在点击率预测中影响很大。

## 2. 源码导航与直观解释

[din.py](din.py) 的 `LocalActivation` 给每条历史行为构造四组信息：候选向量、历史向量、两者差、两者逐元素乘积。小 MLP 把它们变成 `[B,T]` 的激活权重；PAD ID 为 0 的行为被屏蔽。`DIN.forward` 用这些权重对历史向量加权求和，再与候选向量拼接，让分类头输出 `[B]` 点击 logit。运行 `python DIN/din.py` 看小批次形状与梯度。本例保留目标注意力和预测主干，没有论文工业系统的海量特征、Dice 激活、正则和分布式训练。

## 3. 数学解释

设候选嵌入为 `q`，历史嵌入为 `h_t`。局部激活网络算 `a_t=σ(MLP([q,h_t,q-h_t,q⊙h_t]))`；`⊙` 表示逐元素乘积，帮助网络直接看到两个特征是否匹配。用户对候选的兴趣向量为 `u(q)=Σ_t a_t h_t`，因此同一个用户面对不同候选会得到不同的 `u(q)`。最后 `logit=Head([u(q),q])`，点击概率是 `sigmoid(logit)`。与 softmax 注意力不同，源码的各个 `a_t` 独立取 sigmoid，不强制总和等于 1；这保留了用户相关历史行为数量的信息。`history_ids.ne(0)` 确保补齐位置既不产生权重也不进入求和。
