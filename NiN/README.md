# NiN：把小型 MLP 放进卷积窗口

## 1. 出处、提出者与意义

Min Lin、Qiang Chen、Shuicheng Yan 在 2013 年的 [Network In Network](https://arxiv.org/abs/1312.4400) 中提出：普通卷积对每个局部窗口先做线性投影，可在窗口内继续使用小型多层感知机，提高局部表征能力。论文也推广了用全局平均池化替代庞大全连接分类头的做法。NiN 是理解 1×1 卷积为何重要的好起点。

## 2. 源码导航与直观解释

[nin.py](nin.py) 的 `MLPConv` 先做一次 3×3 卷积，再接两次 1×1 卷积；这些 1×1 操作只混合同一空间位置的通道，可看成逐位置共享的小 MLP。`NiN.features` 堆叠多个这样的块，`class_map` 把通道数变成类别数，最后对空间位置求平均。输入 `[B,3,H,W]`，输出 `[B,类别数]`。运行 `python NiN/nin.py`。源码是教学规模，层数和通道数缩小。

## 3. 数学解释

普通卷积的一个输出通道可写成 `zᵢⱼ=Σ₍c,u,v₎K₍c,u,v₎x₍c,i+u,j+v₎+b`。NiN 在这个局部表征上再做 `hᵢⱼ=ReLU(W₂ ReLU(W₁ zᵢⱼ))`，其中 1×1 卷积承担 `W₁/W₂` 的逐位置通道变换。最终类别 `k` 的分数为 `sₖ=(1/HW)Σᵢⱼ F₍k,i,j₎`；每个类别对应一张特征图，再求平均得到分数。

这里的 1×1 卷积并非“没有计算”，它对每个像素位置的通道向量执行同一组可学习矩阵，因此可形成新的特征组合。若把三层都换成独立的全连接层处理整张图，就会失去空间位置上的权重共享。全局平均池化要求类别特征图的通道数与类别数对应，这在 class_map 中明确完成。

这个例子使用小图以便在 CPU 上运行。若想看卷积与 1×1 层的区别，可以分别打印每层输出形状：后者通常保留高宽，只更换通道表征。
