# SENet：让网络按输入重新分配通道权重

## 1. 出处、提出者与意义

Jie Hu 等人在 2017 年的 [Squeeze-and-Excitation Networks](https://arxiv.org/abs/1709.01507) 中提出 SE 模块：卷积不只要识别空间局部模式，也应根据整张图判断哪些通道更值得重视。SE 可插入现有 CNN 块，成为通道注意力的重要起点。

## 2. 源码导航与直观解释

[senet.py](senet.py) 的 `SqueezeExcitation` 先对每个通道做全局平均池化，得到 `[B,C,1,1]` 摘要；两层 1×1 卷积输出 0 到 1 之间的通道权重，然后乘回原特征图。`SEBlock` 将它嵌进残差块，`SENet` 给出小型分类网络。运行 `python SENet/senet.py`；输入 `[B,3,32,32]`，输出 `[B,类别数]`。这里演示 SE 机制，不复制论文大规模 SENet 配置。

## 3. 数学解释

给特征 `X∈R^(B×C×H×W)`，通道摘要为 `z_c=(1/HW)ΣᵢⱼX₍c,i,j₎`。激励门为 `s=σ(W₂ ReLU(W₁z))`，每个 `s_c∈(0,1)`。重标定后的 `X̃_c=s_c·X_c`，因此同一张图中有用通道会被保留，较不相关通道被压低。源码中的 `AdaptiveAvgPool2d(1)`、两层 1×1 卷积和乘法正对应这三步。

假设某张图的一个通道几乎没有响应，它的平均值 z 会较小，但最终门值仍由所有通道的摘要共同决定，因为两层 1×1 卷积在压缩后的通道间混合信息。门值是针对每张输入图重新计算的，不是一组固定的全局缩放参数。SE 的乘法不会改变特征图的宽高与通道数。

读源码时可打印 gate(x) 的形状：它是 [B,C,1,1]，与原特征 [B,C,H,W] 相乘时由广播自动扩展到每个空间位置。每张图片的门值单独计算，批次之间不会混在一起。
