# SSD：一次前向、多个尺度的默认框检测

## 1. 出处、提出者与意义

Wei Liu、Dragomir Anguelov、Dumitru Erhan 等人于 2015 年提出 [《SSD: Single Shot MultiBox Detector》](https://arxiv.org/abs/1512.02325)。SSD 不先生成候选框再逐个分类，而是在不同分辨率的特征图上直接放置多种比例的默认框，并同时预测类别与框调整。高分辨率特征较适合小目标，低分辨率特征提供更大感受野。它是理解单阶段、多尺度、anchor-based 检测器的经典范例。

## 2. 源码导航与直观解释

[ssd.py](ssd.py) 的 `default_boxes` 为每级特征图每个位置建立四种长宽比的框。`SSD.forward` 从较细和较粗的两级特征分别预测类别 logits 与四维位置偏移，然后按相同顺序连接默认框，返回 `[B,N,C+1]`、`[B,N,4]`、`[N,4]`。`training_loss` 先用 IoU 将默认框与真实框匹配，至少保证每个真实框有一个正样本；再按分类损失选取最难的负框，使负例数不超过正例三倍。根目录运行 `python SSD/ssd.py` 可看到形状与反向传播。

教学版只有两个尺度、每位置四个默认框，且没有解码后的置信度阈值与 NMS 推理封装。论文的 SSD300/SSD512 采用更多特征层、尺度与训练策略；此处用小网络保留核心可读计算。

## 3. 数学解释

默认框 `a` 是基准位置，真实框 `g` 转成相对偏移：`t_x=10(g_x−a_x)/a_w, t_y=10(g_y−a_y)/a_h, t_w=5log(g_w/a_w), t_h=5log(g_h/a_h)`。源码 `encode` 就实现这四式；网络回归的 `[B,N,4]` 与它做 Smooth L1。分类头为每个默认框输出背景加 `C` 个类别；正框按 IoU 匹配到对象，负框应是背景。若直接用所有负框，大量容易的背景会主导训练，因此 `training_loss` 在负框中按交叉熵从高到低挑选，这就是 hard negative mining。总损失是分类与定位之和，再用正框数归一化分类部分。
