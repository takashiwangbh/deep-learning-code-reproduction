# 增加一个新论文实现

1. 在合适主题目录增加独立 `.py` 源码文件，文件名使用小写英文与下划线。模型的核心结构、损失或训练更新必须在仓库中可见；不要以 `torchvision.models`、`transformers`、`diffusers`、`timm` 等现成模型导入替代源码。可以用 PyTorch 的基础张量、自动微分和基础层。
2. 在该主题的 README 中写清论文链接、提出年份、核心公式与源码的对应关系、输入输出形状、运行命令，以及任何与原论文不同的简化。不要将随机张量上的前向运行描述成论文指标复现。
3. 给文件加一个可在 CPU 上运行的 `__main__` 小例子，并在主题测试中检查形状、梯度和该算法最容易犯错的数学性质（例如因果掩码、状态递推、采样边界）。将该测试接入 `check_all.py`。
4. 默认依据公开论文独立实现。若确实复制或改编 GitHub 源码，先确认许可证允许再分发，在文件附近保留原作者、仓库地址、许可证文本和改动说明。
5. 训练所需的语料、数据集和模型权重另行下载，不提交大文件、密钥或数据集到 Git。
