# CNN：从局部卷积到图像分类

## 1. 出处、提出者与意义

卷积网络并不对应唯一一篇论文。本项目以 Yann LeCun、Léon Bottou、Yoshua Bengio、Patrick Haffner 1998 年的 [Gradient-Based Learning Applied to Document Recognition](https://doi.org/10.1109/5.726791) 为经典参考，演示后来广泛使用的局部连接、权重共享和池化。与每个像素都连到每个神经元相比，同一个卷积核可以在整张图上重复寻找同一种局部图案。

## 2. 源码导航与直观解释

[cnn.py](cnn.py) 的 `BasicCNN.features` 交替使用 `Conv2d`、ReLU 和最大池化：卷积提取局部特征，ReLU 加非线性，池化缩小空间尺寸。`head` 用全局平均池化和线性层转成类别分数。输入是灰度图 `[B,1,28,28]`，输出 `[B,10]`；运行 `python CNN/cnn.py` 可检查前向和梯度。它是通用教学 CNN，不声称复刻 1998 年的完整 LeNet-5；具体 LeNet-5 请看同名项目。

## 3. 数学解释

对输入 `x` 和一个 `k×k` 卷积核，输出位置 `(i,j)` 由邻域加权求和：`yᵢⱼ=Σ₍u,v₎Kᵤᵥ xᵢ₊ᵤ,ⱼ₊ᵥ+b`，多个输入/输出通道时再对通道求和。同一组 `K` 在所有位置复用，就是权重共享。`3×3, padding=1` 保持宽高；`2×2` 池化把宽高各减半。两次池化后，28×28 大致成为 7×7，最后全局平均把每个通道压成一个数，分类层输出 logits。

若去掉池化，后续特征图会保持更大，计算量和内存也会提高；若把卷积核改为 1×1，它只能混合当前位置的通道，不能直接观察邻近像素。读源码时可以逐层打印张量形状，核对通道从 1 到 8 再到 16 的变化。分类 logits 还不是概率，训练分类任务时通常交给交叉熵损失处理。
